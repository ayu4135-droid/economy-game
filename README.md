# 경제의 갈림길 — 교실 실시간 투표 게임 (입장 대기실/투표/결과 분리)

## 교실에서 사용하기
1. 교사가 사이트에서 **새 게임방 만들기** 클릭.
2. 화면에 표시된 **QR 코드**로 학생들이 입장하며 교사 화면에 참가 인원 실시간 표시.
3. 교사가 **게임 시작 · 첫 상황 공개** 클릭.
4. 프로젝터 화면에는 **라운드 상황 + A/B 선택지 + 실시간 투표 집계**만 표시. 학생은 휴대폰에서 A/B 선택.
5. 교사가 **투표 마감 · 다수결 결과 공개** 클릭하면 **별도 결과 화면**으로 전환되어 채택 정책, 설명, 지표 변화 공개.
6. **다음 라운드** 클릭 시 다음 상황/실시간 투표 화면으로 전환.

동점 시 교사가 결선 정책 선택. 투표 전 학생들의 선택은 공개되지 않음. QR 입장은 학생 별명만 요구함.

## 기존 Render 사이트에 반영하기
- ZIP을 **풀어서** `server.py`, `index.html`, `requirements.txt`, `render.yaml`, `README.md`를 기존 GitHub 저장소 최상위에 업로드(덮어쓰기) 및 Commit changes.
- Render의 최신 배포가 Live인지 확인. 자동 배포가 꺼졌다면 Manual Deploy → Deploy latest commit.
- 사이트를 새로고침하고 **새 게임방** 생성 (기존 실행 중 게임방은 재배포 시 유지되지 않음).

## 배포
Render Web Service Python 3, Build Command: `pip install -r requirements.txt`, Start Command: `python server.py`, 무료 인스턴스 사용 가능. 무료 서버는 유휴 상태에서 잠자기/재시작될 수 있으므로 수업 전 접속 테스트 필수.

주의: 무료 단일 서버의 게임방 데이터는 메모리에만 저장되므로 서버 재시작 시 사라짐. 개인정보를 입력받지 않도록 별명 사용 권장. 30명 동시 접속은 배포 환경에서 실제 확인 필요.
