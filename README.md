# 경제의 갈림길 — 학급 실시간 국가 운영 게임

교사가 게임방을 열고 30명 내외 학생이 휴대폰으로 A/B를 투표합니다. 투표는 WebSocket으로 즉시 서버에 집계되며, 교사가 마감하면 더 많은 표를 얻은 정책에 따라 **반 전체 국가의 점수**가 달라집니다. **문항별 정답 없음**. 시장 경제와 계획 경제라는 단어는 선택지에서 숨겼으며, 게임 뒤 비교할 수 있게 했습니다.

## 실행하기

1. Python 3.10 이상 설치.
2. 폴더에서 터미널을 열고 `pip install -r requirements.txt` 실행.
3. `python server.py` 실행.
4. 교사용 컴퓨터 웹브라우저에서 `http://localhost:8000` 열어 **새 게임방 만들기** 선택.
5. 학생들이 **같은 Wi-Fi**에 연결된 경우, 교사용 컴퓨터의 LAN IP를 알아내 `http://교사컴퓨터IP:8000`으로 접속. 예: `http://192.168.0.12:8000` (예시 주소, 실제 IP 확인 필수). 방화벽에서 해당 포트 허용 필요. 학생 휴대폰 브라우저에서 방 코드와 이름 입력.
6. 교사용 화면에 A/B 선택 인원이 실시간 표시됩니다. **투표 마감 · 다수결 결과 공개** → 결과 설명·지표 변동 → **다음 라운드** 순서로 진행.

### 학생들이 학교 Wi-Fi가 아닌 모바일 데이터로 참여하는 경우

`localhost`나 내부 IP로는 접속할 수 없습니다. 공개 HTTPS 서버에 올려야 합니다.

- GitHub 저장소를 새로 만들어 `server.py`, `index.html`, `requirements.txt`, `render.yaml`을 업로드합니다.
- Render에서 **New → Blueprint**로 저장소를 연결해 배포합니다. 또는 **Web Service**를 만들고 build command `pip install -r requirements.txt`, start command `python server.py`를 입력합니다.
- 제공된 `https://...onrender.com` 주소를 교사와 학생이 함께 접속합니다. 교사가 새 게임방을 만들고 방 코드를 알려 줍니다.
- 무료 플랜 정책/지원 기능은 변경될 수 있습니다. 무료 서버가 잠들거나 재시작되면 방과 기록이 사라질 수 있으므로 수업 전에 테스트하세요.

## 주요 기능과 제약

- 10개 라운드, 5가지 국가 운영 지표(0~100), 이전 정책의 누적효과, 경제 위기·재난 등 돌발상황, 여러 엔딩.
- 학생 투표는 마감 전 수정 가능하며, **같은 브라우저의 중복 투표는 한 표로 집계**. 별도 계정 인증은 없으므로 다른 기기나 브라우저 사용에 의한 중복은 완전히 방지할 수 없습니다.
- 동점이면 교사가 토론 후 A 또는 B를 선택합니다.
- 학생 이름/별명과 투표는 **서버 메모리에만** 보존되며 영구 저장되지 않습니다. 교사의 방 생성 토큰은 해당 탭 세션에 저장됩니다. 실명 대신 번호나 별명을 권장합니다.
- 참가 인원은 방 코드로 참가한 고유 학생 브라우저의 총수이며, 접속 해제 후에도 그 인원은 남을 수 있습니다. 진행 중 연결이 끊어지면 자동 재접속합니다.
- 서버가 종료·재시작되면 모든 방이 초기화됩니다. 교사 탭을 닫은 후에는 해당 방을 조종할 수 없게 될 수 있습니다. 교사 탭을 유지하세요.
- **이 파일만 더블클릭해서는 실시간 기능이 동작하지 않습니다.** 반드시 서버를 실행하거나 배포해야 합니다.
- `render.yaml`은 Render 서버 배포 편의를 위한 구성입니다. 외부 서비스의 현재 플랜 조건은 배포 전에 확인하세요.

## 학습 목표

학생이 경제 문제 해결의 결정 주체, 자원 배분의 효율성, 경쟁과 창의성, 불평등과 환경오염, 정책 목표 달성, 선택의 제한 및 계획 생산의 비효율을 비교합니다. 점수 증감은 상황 이해를 돕기 위한 **가상의 게임 규칙**입니다. 실제 국가의 인과 관계를 단순화한 것이므로 게임 뒤 비판적 토론을 진행하세요.
